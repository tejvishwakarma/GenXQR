Printed menus have one problem: the day you change a price, add a dish or run out of something, every copy is out of date. A QR code menu fixes that, but only if you set it up so that you can change the menu without changing the code.

## Two ways to put a menu behind a QR code

**1. A PDF of your existing menu.** If you already have a designed menu, make a PDF QR code and upload the file; scanning opens it. Quick to set up, and it looks exactly like your printed card. The downside: PDFs are hard to read on a phone (guests pinch and zoom), and every change means editing the design file again.

**2. A menu page built for phones.** You type in your sections (Starters, Mains, Drinks) and the items with their prices, and the QR code opens a clean page with a tab for each section. Text is big enough to read, guests scroll instead of zooming, and changing a price takes seconds from your phone.

For most restaurants and cafes, the second option is better day to day. Keep the PDF for a special-occasion menu or a catering brochure.

## What a good QR menu page shows

GenXQR's menu page has:

- **Your restaurant's name and a short description** at the top
- **Tabs for each section**, so guests jump straight to Drinks or Desserts
- **Each item's name, description and price**, in rupees by default
- **A veg or non-veg mark** on each item, the familiar green and red symbol
- **Allergens** listed under the item, such as nuts, gluten or dairy

You can also choose the page colours to match your brand.

## Step by step

1. **Create a Menu QR code** in your GenXQR dashboard and give it a name you will recognise, such as "Table menu – Connaught Place".
2. **Add sections and items.** Start with what you actually serve today. Mark veg and non-veg, and add allergens where they matter.
3. **Design the code.** Add your logo in the centre and a frame with a call to action such as "Scan for menu". Keep the code dark on a light background; see our [checklist for QR codes that scan](/blog/qr-codes-that-scan-print-checklist).
4. **Test it before printing.** Scan it with an iPhone and an Android phone, under the light at your tables.
5. **Print table cards or standees.** Put the code where guests look first: at the centre of the table or on the card holder, not under the cutlery.
6. **Update whenever you need to.** Edit the menu in the dashboard and the next guest who scans sees the new prices. The printed code never changes.

## Use the scan data

Because the menu is a dynamic QR code, you can see when it is scanned: which days and hours are busiest, and whether guests use iPhones or Android phones. If you run more than one outlet, give each outlet its own code and add it as a separate [place](/features), so you can compare them.

## Common mistakes

- **Printing a static QR code that points to a PDF link.** If you ever move or rename the file, every table card breaks. Use a dynamic code so the destination can change.
- **Codes that are too small.** On a table card, the code should be at least about 2.5 cm wide. Bigger is safer.
- **Glossy lamination under bright lights.** Reflections hide parts of the code. Matte lamination scans more reliably.
- **No paper fallback.** Keep a few printed menus for guests whose phones are flat or who prefer paper.
